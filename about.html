About Random Adventure

Random Adventure is a website designed for people who have free time but do not know what to do.

The website provides different activities that users can explore based on their interests, available time and budget.

How It Works

  1. Visit the website.
  2. Explore different adventures.
  3. Choose an activity.
  4. Try something new.

Our Project

This project is being developed as part of our Web Programming course.

The first phase focuses on creating the website structure and visual design using HTML and CSS. Future phases can add JavaScript functionality and a backend database.
